# Changelog

All notable changes are documented here.

## [0.1.0] - 2026-08-11

### Added

- rights-aware Codex Skill and deterministic Python CLI;
- Gutendex and Google Books search and fetch support;
- EPUB, PDF, HTML, text, MOBI, and AZW conversion paths;
- provenance records with rights signals and SHA-256;
- HTTPS/domain/redirect controls and IP-literal rejection;
- archive expansion, hardened XML parsing, download, and subprocess limits;
- signature checks, no-overwrite output publication, and untrusted-content markers;
- offline tests, CI, CodeQL, Dependabot, contribution guidance, and security policy.
